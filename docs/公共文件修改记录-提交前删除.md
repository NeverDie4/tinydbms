# 公共文件修改记录（临时）

## 本轮修改

### `include/tinydbms/core.hpp`

- `OpenDatabaseRequest.data_dir` 的注释明确为：由入口补全，传入 core 时不能为空。
- 移除测试专用的 `testing::DatabaseAccess` 前置声明和 `friend`，避免测试入口进入公共头文件。
- 行为测试改为通过 fake compiler 预置 Plan，再调用公开 `Database::execute_script`。

### `include/tinydbms/storage.hpp`

- `OpenStorageRequest.data_dir` 的注释明确为：由 core 传入，不能为空。
- 默认目录由 CLI 负责补全，storage 不负责解释空字符串默认值。

## 需要同步给其他成员的契约

1. CLI 未指定 `--data-dir` 时补全 `./tinydbms-data`；core 和 storage 收到空字符串时返回错误。
2. `Database::execute_script` 是行为测试和产品入口使用的统一执行入口。
3. `include/tinydbms/` 属于公共契约；字段、函数签名、错误语义、生命周期语义和责任边界发生变化时，必须先通知依赖 compiler、storage、app 的成员。
4. `src/core/` 下的 `internal.hpp` 仅供 core 内部使用，不安装、不进入公共 include 路径。
